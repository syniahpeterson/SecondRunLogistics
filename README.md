# 🚛 Second Run Logistics

A responsive business website built for **Second Run Logistics LLC**, a local trucking company. The project was designed to establish a professional online presence, clearly communicate the company's services, and provide prospective customers with an easy way to get in contact.

> **Portfolio Project:** A freelance frontend development project demonstrating React, responsive design, reusable components, API integration, custom branding, and production deployment.

---

## 🌐 Project Overview

Second Run Logistics needed a professional web presence that could clearly communicate its services while providing prospective customers with a straightforward way to connect with the company.

I designed and developed the website from the ground up, translating the client's business requirements and branding preferences into a responsive React application.

The project focused on:

* Responsive web design
* Component-based React development
* Reusable UI components
* Mobile-friendly navigation
* Custom visual branding
* Contact form integration
* User-focused information architecture
* Cross-device usability
* Production deployment and maintenance

The repository is organized as a Vite-powered React application with dedicated components, sections, hooks, assets, and styling.

## 🧩 Project Architecture

The application uses a component-based structure that separates reusable UI, page sections, hooks, assets, and styling.

```text
srl/
├── public/
│
├── src/
│   ├── assets/
│   │
│   ├── components/
│   │
│   ├── hooks/
│   │
│   ├── sections/
│   │
│   ├── styles/
│   │
│   ├── App.css
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
│
├── .gitignore
├── eslint.config.js
├── index.html
├── package.json
├── package-lock.json
└── vite.config.js
```

This organization allows reusable components and sections to remain separate from application-level files and styling.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/syniahpeterson/SecondRunLogistics.git
```

### Navigate to the Project

```bash
cd SecondRunLogistics/srl
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Vite will start the local development server and provide a URL where the application can be viewed.

---

## 📦 Available Scripts

### Development

```bash
npm run dev
```

Starts the Vite development server.

### Production Build

```bash
npm run build
```

Creates an optimized production build.

### Preview

```bash
npm run preview
```

Previews the production build locally.

### Deploy

```bash
npm run deploy
```

Builds and deploys the application using GitHub Pages.

The project's `package.json` includes dedicated development, production build, preview, pre-deployment, and GitHub Pages deployment scripts.
